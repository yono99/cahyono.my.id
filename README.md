# cahyono.my.id

Personal portfolio — **Cahyono**, Fullstack Web Developer.

**Live:** [https://cahyono.my.id](https://cahyono.my.id)

## Stack

- Static HTML/CSS/JS (no build step)
- Hosted via GitHub Pages + custom domain

## Structure

```
├── index.html          # Main portfolio page
├── assets/
│   ├── app-home.jpg    # nilaia screenshots
│   ├── app-tryout.jpg
│   ├── app-hasil.jpg
│   ├── figural-demo.gif
│   └── portrait.jpg    # Optional professional photo (1:1)
├── CNAME
├── robots.txt
└── sitemap.xml
```

## Optional: add a portrait photo

Place a professional headshot at `assets/portrait.jpg` (square, min 600×600px).  
The page auto-detects it and replaces the monogram initial.

## Local preview

Open `index.html` in a browser, or:

```bash
npx serve .
```
